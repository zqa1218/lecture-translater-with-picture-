PPT 课件学习助手 v2.2 — 使用说明
========================================

一、首次使用（填写 API Key）
1. 从开始菜单或桌面快捷方式启动「PPT课件学习助手」。
2. 在「① 课件翻译」页填入 DeepSeek API Key（任何兼容 OpenAI 接口的服务均可），
   勾选「记住 API Key」后会自动保存。
3. 设置保存在 %APPDATA%\PPT课件学习助手\translator_config.json，
   覆盖安装或升级不会丢失。

二、翻译课件（.pptx / .pdf）
1. 把课件拖进窗口，或点「选择文件」。
2. 保持「翻译图片内文字」为勾选状态（默认开启）。
3. 点「开始翻译」。结果保存为 <原文件名>_Chinese.pptx，与课件同目录；
   同名文件不会被覆盖，会自动加 _2、_3。

三、图片内文字翻译
- 插图、流程图、坐标轴、图注里的英文会被本地 OCR 识别后翻译，识别过程离线完成。
- 图片的尺寸、位置、裁剪、旋转保持不变，幻灯片版式不会被改动。
- 公式、变量名和无需翻译的缩写保持原样。
- 译文放不进原文字框时会保留原文，不会出现文字被擦掉却补不回来的情况。

四、命令行批处理（可选）
  "PPT课件学习助手.exe" --cli <文件或文件夹> --out <输出目录>
  追加 --report <报告.json> 可输出机器可读的结果报告。

五、常见问题
- 提示「未知发布者」：本程序未做数字签名，点「更多信息」→「仍要运行」即可。
- 首次识别图片偏慢：需要加载本地 OCR 模型，属正常现象。
- 提示 API 报错：检查 API Key、账户余额与网络；可在设置里调低并发数后重试。
- 卸载：Windows 设置 → 应用 → 已安装的应用 → PPT课件学习助手 → 卸载。
